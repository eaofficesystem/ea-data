# سجل توثيق الوارد — نسخة GitHub فقط

هذه النسخة مخصصة للتشغيل على **GitHub Pages فقط**.

## الملفات المطلوبة
- `index.html` — ملف المنصة الرئيسي.
- `README_AR.md` — هذه التعليمات.

## تسجيل الدخول الافتراضي
- المدير: `admin` / `ea2026`
- المفوض بالإضافة: `editor` / `ea2026`

إذا سبق تغيير بيانات الدخول من داخل المنصة، فستُستخدم البيانات المحفوظة في المتصفح بدل الافتراضية.

## GitHub
إعدادات GitHub موجودة داخل المنصة للمدير، وتشمل المستخدم والمستودع وToken، وتُستخدم لمزامنة `data.json`.

لا توجد في هذه النسخة Netlify أو Functions أو Backend خارجي.
